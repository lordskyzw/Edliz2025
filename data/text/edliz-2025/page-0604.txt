Chemotherapy can be used in a number of ways. The criteria for use differ for
each tumour type, stage, morphologic and biologic characteristics. Combination
chemotherapy is more commonly used than single agent chemotherapy.
Other Systemic Therapies
Recently, there has been development of an array of agents that are specific to
certain molecules. These targeted therapies include hormonal therapy, small
molecule inhibitors, monoclonal antibodies and immunotherapy.

Principles of Combination Chemotherapy
1.Each agent used should have a different mechanism of action
2.Each agent should ideally be used at maximum dose
3.Agents with similar dose-limiting toxicities can be combined safely only by
reducing doses, resulting in decreased toxic effects.
4.Combination chemotherapy should be administered according to protocol, based
on evidence-based medicine with intervals between therapy cycles allowing for
the recovery of normal tissue.
